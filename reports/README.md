# 研究输出与结果来源

本目录只保存适合提交的运行摘要、图表及失败分析。完整数据、环境、权重、缓存和逐查询原始工件保留在本地 `artifacts/`，不提交Git。

每份结果应明确：

- run ID、开始/结束UTC时间、最终状态（成功/失败/中断/预算停止/未收敛）和退出码。
- 项目与上游commit、完整配置路径及hash、环境锁、Python/Torch/RDKit版本。
- 数据revision及原始文件hash、标准化规则、分子角色清单hash、候选机制/K/种子/清单hash。
- checkpoint hash、训练种子、精度、模型选择角色；使用预训练时说明数据暴露核查及局限。
- 指标定义、全部分母、有效分子数与过滤保留率；重复谱图和模型种子不得当独立校准样本。
- 原始输出/日志/checkpoint在 `artifacts/runs/<run_id>/` 的位置、峰值显存/RSS、GPU墙钟与磁盘/下载量。
- calibration/test是否封存以及产物读取权限；正式cal一次验证失败也作为结果保存。

图表由原始结果自动生成，论文每项数字绑定run ID与配置；禁止凭手工抄数维护第二份结果来源。零接受的接受错误率为未定义；unknown FAR与集合覆盖率分开报告。不同候选机制、信息条件、K和分母不能未经说明直接合并。

科学来源与实验结果分开：`docs/evidence.jsonl`保存论文声明、静态代码和工件可达性，不能代替运行日志。100查询闭环和小规模训练只证明流程可执行，不证明论文数值已经复现，也不构成研究创新或正式校准证据。
